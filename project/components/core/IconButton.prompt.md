Icon-only button — for header chrome (cart, language), the composer (send, mic) and inline quantity/remove actions.

```jsx
<IconButton icon="shopping-cart" variant="chrome" ariaLabel="Cart" />
<IconButton icon="send" variant="solid" />
<IconButton icon="minus" variant="soft" size={26} />
```

Variants: `chrome` (translucent white on purple header), `soft` (purple-100), `solid` (purple), `danger` (red). Press shrinks to 92%.
