Compact status / metadata pill — discounts, stock, category tags over product images, the yellow cart count and "● LIVE" indicator.

```jsx
<Badge tone="success">-20%</Badge>
<Badge tone="purple">Cakes</Badge>
<Badge tone="accent">3</Badge>
<Badge tone="ink">Out of Stock</Badge>
```

Tones: `neutral`, `purple` (translucent over imagery), `accent` (yellow), `success` / `warn` / `error`, `ink`. Fully rounded; `purple`/`ink` blur the backdrop so they stay legible on photos.
