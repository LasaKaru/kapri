One-sentence: A lucide-faithful outline icon used for all functional UI glyphs.

```jsx
<Icon name="shopping-cart" size={18} />
<Icon name="check-circle" color="var(--success)" />
```

Use lucide names (`shopping-cart`, `external-link`, `check-circle`, `truck`, `calendar`, `alert-triangle`, `send`, `mic`, `plus`, `minus`, `trash-2`, `x`, `chevron-right`, `sparkles`, `package`, `map-pin`, `phone`, `clock`, `gift`). Inherits `currentColor` unless `color` is set. For categories/celebration use emoji instead.
