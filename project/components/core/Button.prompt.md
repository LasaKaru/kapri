Brand action button — use for any primary/secondary action; the **yellow** variant is the high-emphasis CTA ("Pay Now", "Checkout") and should appear at most once per view.

```jsx
<Button variant="yellow" size="lg" fullWidth>Pay Now on Kapruka</Button>
<Button variant="primary">Add to Cart</Button>
<Button variant="secondary" size="sm">View details</Button>
```

Variants: `primary` (purple fill), `secondary` (purple outline), `ghost` (text only), `yellow` (accent CTA). Sizes: `sm` / `md` / `lg`. Press shrinks to 95%. Yellow on purple, purple text on yellow — never yellow text.
